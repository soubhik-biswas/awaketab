# 07 · Internationalisation (i18n)

Status: v2.0 · 2026-11-13 · Owner: Soubhik

**Purpose.** How AwakeTab ships in eight languages without the machine-translation tells that undermine the competitors: routing, string files, formatting, the translation workflow, localised keyword research and the QA bar. Localisation is an SEO investment as much as a UX one: each locale is a separate results page we can win.

Related docs: `00-conventions.md` §7 (locales, routes) · `05-frontend-spec.md` (where strings render) · `06-content-seo-spec.md` (hreflang, translated slugs, the sitemap) · `13-testing-strategy.md`.

**Where it lives.** Locales and their tags are in `apps/site/i18n/locales.ts`, routing in `apps/site/i18n/routing.ts` (`next-intl`), the message loader in `apps/site/i18n/request.ts`, UI strings in `apps/site/messages/{locale}.json`, translated slugs in `apps/site/i18n/slugs.json` and translated articles in `apps/site/content/{collection}/{locale}/`.

## 2. Routing

English is at the root and the other locales under their prefix (`localePrefix: 'as-needed'`). There is no redirect by `Accept-Language`, no locale cookie and no `Link` header: the site sets no cookies, and unreviewed translations carry no hreflang.

- **In every language:** the home page with the tool, the ten translated articles of §5, the offline page, the not-found page, the mini clock popup (`/{lang}/pip`) and the widget app (`/{lang}/embed/cook`).
- **English only:** the hubs, preset and until pages, product pages, help, about, legal, changelog, status and the Pro flow. Their locale prefixes answer 404, so no language serves an untranslated copy; a translated page links to them with `hreflang="en"`.
- The language menu links each page's own translation, or the locale home when there is none.
- A page exists in a locale only as a real translation. Until a native reviewer signs it off it is live but `noindex`, out of the sitemap and hreflang, and labelled "Translated from English — native review pending" with a link to the English original (`reviewed` in the article, `LOCALE_META[locale].reviewed` for the home).

## 3. UI strings

`apps/site/messages/{locale}.json` is nested by namespace and read with `next-intl`. A key that is also a group keeps its own text under `_` (`site.cta._`). `en.json` is the source of truth.

| Namespace | What it holds | In every language |
|---|---|---|
| `tool.glance` | The tool: top bar, set mode, dock, pill, panels, banners, toasts, palette, screen-reader messages | yes |
| `face` | Clock face names and drawn words | yes |
| `site` | The page shell: header, footer, consent card, home story, article chrome, system pages | yes, except the keys of English-only pages |
| `content` | Article chrome: family labels, "Sources checked", steps, checklists | yes |
| `surfaces`, `embed` | The mini clock, widgets, wall mode and the website widget | yes |
| `page` | Titles and descriptions of site pages | `page.home` and `page.pip` in every language; the rest English only |
| `account`, `proflow` | Sign-in and the Pro flow | English only |

Rules:

- A locale file holds only keys that exist in `en.json`, with the same placeholders. A key a locale leaves out falls back to English at load time (`apps/site/i18n/request.ts`), so strings of English-only pages are simply absent from the other files.
- ICU syntax for variables and plurals (`{n, plural, one {# command} other {# commands}}`); never string concatenation.
- A string that only makes sense with Pro has a no-Pro twin with the suffix `Free` (`site.story.bento.free.dFree`), and the component picks one by `PRO_ENABLED`.
- No email address, price or internal code in any string. Placeholders the design leaves open stay in `[BRACKETS]`.

## 4. Formatting rules

| Concern | Rule |
|---|---|
| Times | `formatTime` in `apps/site/lib/format.ts`: English always reads "11:42 AM"; other locales follow their own convention (11:42 · 午前11:42 · 上午11:42 · सुबह 11:42) unless the 12-hour setting says otherwise |
| Dates | Always the full date: "Saturday, 26 September 2026" in English, `dateStyle: 'full'` elsewhere (`formatFullDate`). An end time past midnight says "tomorrow" |
| Countdown digits | Always `tabular-nums` and Latin digits, in every locale |
| Plurals | ICU `{n, plural, …}` |
| Text length | Allow German and French 40 % more, Hindi 20 % more: buttons and the top bar grow, and nothing truncates. The status pill may wrap to two lines |
| Accent word | The serif italic accent is used for Latin scripts only; other scripts keep the gradient, and the accent phrase never breaks across lines |
| Script fonts | Japanese, Chinese and Hindi use Noto Sans JP, SC and Devanagari after Inter |
| Product terms | `AwakeTab`, `Pro`, `Wake Lock` untranslated |

## 5. Content translation workflow

1. **Source**: the English article is finished, fact-checked and has `lastVerified`.
2. **Brief**: the translator receives the page's `intent` in English, the localised target query (§7), the audience, the honest limit (which must not be softened) and the glossary (§10).
3. **Translate** into `apps/site/content/{collection}/{locale}/{english-slug}.md` with `translationOf: "<english-slug>"`; a translated slug for `es`, `pt-br`, `de` or `fr` goes into `apps/site/i18n/slugs.json`.
4. **Native review** against the checklist in §8.
5. **Publish**: flip `reviewed: true`; the page joins the sitemap and the hreflang set of every indexable version automatically.
6. **Maintain**: when the English source changes, apply the same correction to every translation in the same change. Tool wording quoted in an article (pill text, button and panel names, lengths) comes from that locale's `tool.glance` strings.

Machine translation may produce the first draft; it never becomes indexable without step 4. The translated set is the ten top pages: `/for/cooking`, `/for/downloads`, `/for/presentations`, `/on/iphone-safari`, `/on/android-chrome`, `/on/windows-11`, `/on/macos`, `/guides/iphone-auto-lock-never-greyed-out`, `/vs/caffeine` and `/learn/browser-support-matrix`. Translations are adaptations for the local query, not word-for-word copies, and `related` holds English route paths that the page resolves to the same-locale version when one exists.

## 6. Right-to-left readiness

Use logical properties everywhere (`margin-inline-start`, `padding-inline`, `inset-inline-end`, `text-align: start`). The ring, the progress direction and the charts are direction-neutral. Adding Arabic then needs `dir="rtl"` on `<html>` and mirrored chevrons, with no layout work.

|---|---|---|

| `fr` | garder l'écran allumé · empêcher l'écran de s'éteindre · écran toujours allumé · empêcher la mise en veille | |
| `ja` | 画面をスリープさせない · 画面 消えない ようにする · スリープ 防止 ブラウザ · 画面 常時点灯 | Search behaviour favours problem phrasing |
| `zh` | 保持屏幕唤醒 · 防止屏幕休眠 · 屏幕常亮 网页 · 电脑不休眠 | "常亮" is the natural term |

Each locale gets its own `intent` and `secondaryQueries` in the frontmatter; titles are written for the local query, not translated from English.

## 8. Translation QA checklist (native reviewer)

- [ ] Meaning matches the English source, including every limit and caveat (nothing softened, nothing promised).
- [ ] Reads as written by a native speaker: no calques, no machine-translation tells (odd articles, literal idioms, inconsistent formality).
- [ ] Product terms untranslated (`AwakeTab`, `Pro`, `Wake Lock`); UI labels match the shipped `{locale}.json` exactly when quoted.
- [ ] Title ≤ 60 characters (CJK: ≤ 30 full-width), description ≤ 155 (CJK ≤ 80); H1 targets the local query.
- [ ] Numbers, dates, times and units in local convention; timer digits Latin.
- [ ] Screenshots localized or clearly English with a note.
- [ ] Layout check at 320 px and 1280 px in that locale (no clipped chips, no overflowing pill).
- [ ] Links point to the same-locale page where one exists, otherwise to English with `hreflang` intact.
- [ ] `translationOf`, `lastVerified` and translated slug present.

---

## 9. Checks

- Every key in a locale file exists in `en.json`, and its placeholders are identical.
- Every namespace marked "in every language" in §3 is complete in all eight files.
- A pill or button string is at most 1.6 times the English length.
- Hreflang is reciprocal, and translated slugs are unique within a collection and locale.
- An article quotes the tool only in the words of its own locale's `tool.glance` strings.

## 10. Glossary of untranslatables
