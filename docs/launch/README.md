### Maker’s first comment

```text
Hi Product Hunt — I'm [MAKER NAME], and AwakeTab started with a recipe.

My laptop kept going dark while I had flour on my hands. Every "keep awake" tool I tried was either a tiny toggle that quietly stopped working, or wanted an install and an account first.

So we built the opposite:
• One click, and a big clock shows how long your screen will stay on
• It's honest — if battery saver or the browser blocks it, you see that in words, with the fix
• 46 clock faces and six living backgrounds, because you'll be looking at it
• Everything is free. Pro is optional and only for syncing many screens

It runs in the browser with nothing to install, and as a Chrome extension if you want it in the toolbar.

What would you keep awake — and which face do you pick first? Feedback goes straight to us from Settings → Send feedback.
```
